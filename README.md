# MacroTrace
<img src="https://raw.githubusercontent.com/st-chd/chd-asset/refs/heads/main/Asset-MacroTrace/sample.png">
SillyTavern Chat Completion 프리셋의 매크로가 최종 프롬프트에 어떻게 들어가는지 보여 주는 확장입니다.
결과를 누르면 그 값을 만든 매크로로 이동하고, 변수 값은 처음 넣은 `setvar`까지 따라 올라갑니다.

## 요구 사항

- SillyTavern 1.19.0 이상
- 사용자 설정의 `Experimental Macro Engine`이 켜져 있어야 합니다. (1.19.0 기본값)
- 주석 번역을 쓰려면 연결 프로필(Connection Manager)이 하나 이상 있어야 합니다.

## 설치

확장 메뉴의 `Install extension`에 아래 주소를 넣습니다.

```
https://github.com/st-chd/MacroTrace
```

## 사용 방법

확장 메뉴(마법봉)에서 `매크로 추적`을 누르면 창이 열립니다.
위쪽에서 프리셋을 고르면 지금 캐릭터, 페르소나, 채팅, 변수로 계산합니다.

저장된 프리셋을 읽습니다. 프롬프트 매니저에서 고친 내용은 프리셋을 저장한 뒤 `다시 계산`을 누르면 반영됩니다.

## 주요 기능

### 프롬프트 (왼쪽)

- 프리셋의 프롬프트를 순서대로 모두 보여 줍니다. 꺼진 프롬프트는 흐리게 표시합니다.
- 카드마다 번호, 이름, 쓰인 매크로, 원문이 나옵니다.
- 원문에서 실행된 매크로는 색으로, `{{if}}`에서 고르지 않은 쪽은 흐리게 표시합니다.
- `Char Description` 같은 마커 카드에는 캐릭터 카드의 해당 칸 원문이 나옵니다.
- `setvar` 같은 매크로에 마우스를 올리면 값이 어떻게 바뀌었는지 보입니다. 예: `mood: 없음 → 평온`
- 카드 제목을 누르면 접히고 펼쳐집니다. `전체 열기`, `전체 접기`는 모든 카드에 적용됩니다.
- 카드의 ⛶ 버튼으로 원문을 크게 봅니다. 크게 보기 안에서도 단어를 찾고, Esc로 닫습니다.
- 검색하면 검색어가 든 카드만 남습니다.

### 미리보기 (오른쪽)

- 최종 프롬프트를 역할(system, user, assistant)별 메시지로 보여 주고, 매크로 결과가 들어간 자리를 표시합니다.
- 결과를 누르면 왼쪽에서 그 매크로가 있는 곳으로 이동합니다.
- 변수에서 읽은 값을 누르면 위쪽에 경로가 나옵니다.

  ```
  값 ← ③ {{getvar::최종}} ← ② {{setvar::최종::…}} ← ② {{getvar::어떤내용}} ← ① {{setvar::어떤내용::…}}
  ```

  카드에서 지금 표시된 매크로를 다시 누르거나 경로의 칸을 누르면 다음 단계로 넘어갑니다.
  `{{setvar::이름}}…{{/setvar}}`처럼 닫는 태그가 있는 매크로와 `{{getvar::{{getvar::이름}}}}`처럼 이름을 변수로 고른 경우도 따라갑니다.
  경로가 길면 오른쪽 위 버튼으로 접습니다.
- 검색하면 찾은 글자를 표시하고 ↑↓나 Enter로 이동합니다. 접힌 채팅 메시지도 펼쳐서 찾습니다.

### 주석 번역

- 위쪽의 번역 버튼을 누르면 프리셋의 `{{// }}`, `{{//}}…{{///}}` 주석을 고른 연결 프로필로 한국어로 번역해 보여 줍니다. 다시 누르면 원문으로 돌아갑니다.
- 번역은 한 번의 요청으로 보내고, 결과는 브라우저에 저장합니다. 이미 번역한 주석은 다시 요청하지 않습니다.

### 그 외

- 화면이 좁으면 `프롬프트`, `미리보기` 탭으로 나눠 보여 줍니다.
- 테마의 강조색을 따라가고, 어두운 테마에서도 창은 밝게 표시합니다.

## 알아 둘 점

- 창 안에서 `setvar`가 실행되어도 실제 채팅 변수와 전역 변수는 바뀌지 않습니다.
- 실제 생성 과정을 따라 계산한 결과입니다. 다음은 계산하지 않습니다.
  - 월드 인포 (자리만 표시)
  - 작가 노트와 다른 확장이 넣는 내용
  - 정규식
  - 토큰 한도에 따른 채팅 자르기
  - 그룹 채팅의 세부 동작
  - Text Completion 프리셋
- `{{random}}`, `{{roll}}` 같은 매크로는 계산할 때마다 결과가 달라질 수 있습니다.
